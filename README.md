# AI for Interdisciplinary Design — Midterm Portfolio

Shreya Ramanan's DSC 598 midterm portfolio website.

## Pages

- `index.html` — interactive homepage
- `stitched-heart.html` — album-cover project
- `personal-studio.html` — 3D-environment project

## Preview locally

Run a local static server from this folder and open the displayed address in a browser.

```sh
python3 -m http.server 8000
```

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Push the contents of this folder to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Wait for the deployment to finish and test the public URL in a private browser window.
