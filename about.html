About

Made with AI. Decided by hand.

I am Shreya Ramanan. This site collects my work from AI for Interdisciplinary Design at Arizona State University: a game, an album cover and a room, each made with generative tools and each shaped by decisions the tools could not make for me.

The thread running through the site began as a single stitch on an album cover. It became the drawing you can pull across the homepage, and it describes how I now think about these systems: carefully made, easy to unravel, and worth checking at every knot.

Method

Define · Measure · Refine · Audit

The midterm version of this site had three steps. The final project added a fourth.

01

Define

Translate a mood or a brief into observable decisions: one heart, low and left; three zones; four anchors.

02

Measure

Give every decision a value you can check—placement, scale, RGB, colour temperature—so you can see what changed.

03

Refine

Change one variable at a time. Keep what works. Assign each reference a single role.

04 · new

Audit

Assume the system changed something you did not ask for, and look for it. The game makes this step playable.

How this site was made

Design. One accent—the red of the album's thread—on warm black, so the work supplies the colour. Titles are set in Boska (Indian Type Foundry, via Fontshare); everything else in Helvetica Neue. The dark, image-first works grid and per-project “make of” structure take cues from media-art portfolios, where process is shown as seriously as the result.

Build. Plain HTML, CSS and JavaScript with no frameworks or trackers, hosted on GitHub Pages. Every page works without signing in. Interactive pieces are keyboard accessible and respect reduced-motion settings.

AI assistance. The code was written with AI coding assistants (Codex for the midterm site and game drafts; Claude Code for the final cut and this redesign) working from my direction. All concepts, art direction, writing choices and editorial decisions are mine. Each project page has its own ledger of what AI did and what I decided.
